**LEGACY CODE**

Quick and unstructured prototype environment for the following idea:

- Bayesian Inference is extremely fast when using Gaussians + Linear maps
  (the posterior distribution will be Gaussian, too)
- Now, take a non-linear map on the path space
- Linearize it using the Signature Transform
- Apply Bayesian techniques in this linearized setting

I believe there is potential in this strategy when working with functionals
on time series, such as payoff functions in computational finance.

The goal of this repository is not to share working code,
but to convey an idea. Collaboration is always welcomed!
